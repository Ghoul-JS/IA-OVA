# 🤖 IA Explorer — Portafolio Web Interactivo

**IA Explorer** es un sitio web moderno y educativo que explora la **Inteligencia Artificial**, sus aplicaciones y su futuro.  
Desarrollado con **HTML, CSS y JavaScript modular**, combina diseño responsive, animaciones suaves y buenas prácticas de accesibilidad.

---

## 🚀 Características

- 💡 Diseño **moderno y adaptable** a móviles, tablets y PC.  
- 🧩 Código **modular y escalable** (JS dividido por funciones).  
- 🧠 Secciones informativas sobre IA: introducción, aplicaciones, futuro.  
- 🎞️ **Carrusel multimedia** con imágenes y videos.  
- 💬 **Formulario validado** con feedback visual y modal de éxito.  
- ♿ **Accesibilidad ARIA** y navegación fluida por teclado.

---

## 🧩 Módulos Principales

- **NavigationModule:** control del menú y desplazamiento suave.  
- **FormModule:** validación interactiva del formulario.  
- **ModalModule:** apertura/cierre de modales y mensajes.  
- **CarouselModule:** carrusel responsive con soporte táctil.  
- **AnimationModule:** efectos de entrada con IntersectionObserver.
